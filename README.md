# 🚀 Thai Server Game Proxy & Optimizer System

ระบบ Proxy อัจฉริยะสำหรับจัดการการเชื่อมต่อ ปรับแต่งความหน่วง (Latency) และเสริมเสถียรภาพการทำงานสำหรับเซิร์ฟเวอร์ไทยโดยเฉพาะ 

## ✨ Key Features
* **Thai Server Optimizer:** ปรับแต่ง Packet และ TCP Window Size ให้วิ่งฉิวไม่มีสะดุด
* **Render & Buffer Fixer:** ดักจับ Error และเคลียร์ Buffer อัตโนมัติ ป้องกันอาการหลุดระหว่างใช้งาน
* **Mobile & PC Ready:** รองรับการทำงานอย่างไร้รอยต่อ
